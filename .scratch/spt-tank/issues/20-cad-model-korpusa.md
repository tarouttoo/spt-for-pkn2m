# 20 — CAD-модель корпуса: компоновочный прототип

Type: prototype
Status: resolved
Blocked by: —

## Question

Построить CAD-модель корпуса СПТ как дешёвый артефакт для реакции (в духе тикета 02):
проверить компоновку позиций 1–11, зазоры (фильтр vs ТЭН-трубки, кожух vs патрубки)
и гипотезу «референсный габарит 850×500×800 = D420 + изоляция 40 мм» как вход в тикет 05.
Инструмент: text-to-cad (cadgen/build123d), форматы STEP + GLB. Начинка — условные
объёмы отдельным слоем. Все размеры — заглушки ⚠️ (тикет 05 открыт, расчёт не выполнялся).

Решения владельца (рация 1–2, grilling): корпус детально / начинка условно; назначение —
прототип для реакции; STEP+GLB; файлы в `.scratch/spt-tank/cad/`; D420, стенка 4 мм,
днища 2:1 с отбортовкой 40 мм, уклон 40 мм в лапах; изоляция 40 мм и начинка —
переключаемые слои; фланец ТЭН-блока — заглушка.

## Answer

Модель собрана (text-to-cad / cadgen 0.7.21 / build123d): `cad/src/spt_korpus.py` →
`cad/STEP/spt_korpus.step` + `cad/GLB/spt_korpus.glb`. Слои: `korpus` (обечайка + днища +
патрубки 1–10 + 4 листовые лапы, сталь, единая деталь), `izolyaciya_kozhuh` (изоляция 40 мм +
кожух 1 мм, с вырезами на присоединениях, коробке и лапах), `nachinka` (условные объёмы:
3 ТЭН-трубки + траверса, фильтр у поз. 1, коробка соединительная, термометр БТ, ДТС).

### Принятые заглушки (⚠️ всё требует подтверждения в тикетах 05/03/12)

| Параметр | Значение | Примечание |
|---|---|---|
| Обечайка | D420 × 310, стенка 4 | внутренний объём 69,9 л ≈ ~70 л; попровка к раунду 2: 365 не учла объём отбортовок |
| Днища | эллиптические 2:1, глубина 105, отбортовка 40 | ⚠️ D420 — нестандарт для ГОСТ 6533 (ближайшие 400/500) |
| Габарит корпуса (без арматуры) | 600 длина × 420 ⌀ | торец A — низкий |
| Уклон | 40 мм заложен наклоном сосуда, лапы вертикальные до пола | лапа A ~180, лапа B ~209, лист 110×8 |
| Патрубки | DN по тикету 02 (1: DN25, 2: DN15, 3: DN20, 5: DN20, 6: DN15, 9: DN20; гильзы 7/8 G½; шпилька 10 М12) | фланцы плоские без крепежа, ⚠️ |
| Фланец ТЭН-блока (поз. 4) | патрубок ⌀133 + фланец ⌀150 | «по ТЭН-блоку, уточнить» |
| Изоляция + кожух | 40 + 1 мм, сплошная с вырезами | заглушка до тикета 03 |

### Проверки (все PASS, `cad/tmp/check_korpus.py`)

- Габарит сборки с кожухом: **776 × 502 × 678 мм** против референса 850×500×800.
  Вывод для тикета 05: длина сходится (776 + краны/арматура ≈ 850), ширина сходится
  (D420+40+кожух = 502 ≈ 500), **высота меньше на ~120 мм** — либо в референсе выше опоры,
  либо габарит снимается с арматуры/рукавов. Гипотеза «850×500×800 = D420 + изоляция 40»
  подтверждена по ширине и длине, по высоте — вопрос.
- Внутренний объём 69,9 л; уклон концов 40,0 мм; лапы на полу (z=0); все слои положительного
  объёма; начинка внутри полости (макс. радиус 172 < Rвн 206).
- Верхняя образующая: гильзы 7/8, коробка, перелив 5, воздухоотвод 6 размещены без коллизий;
  перелив отведён по ширине (y=−105) из-за тесноты у торца B.
- Снапшоты: `cad/tmp/review_{iso,side,top}.png`. Визуальное ревью агентом НЕ выполнено
  (модель сессии без поддержки изображений) — смотреть в CAD Viewer;
  детерминированные проверки прошли все.
